# UULinker · Android

**把随身 Wi-Fi 的电量、充电状态、网络速率和流量，放到安卓桌面。**

[下载 v1.6.28 测试 APK](https://github.com/MichaelJiangg/Android-UULink/releases/download/v1.6.28/UULinker-Android-1.6.28-test.apk) · [v1.6.28 · 新增原厂接入方式](https://github.com/MichaelJiangg/Android-UULink/releases/tag/v1.6.28)

适用于 Android 8.0 及以上。支持三种接入：**原厂系统（免密 goform 只读）、UFI 高级后台、OpenWrt 设备端插件**。**v1.6.28 为公开测试版，桌面组件的真机视觉仍待补充确认。** 本仓库只提供产品说明与安装包，不提供应用源码。

本版重点新增原厂系统接入方式：设备默认 `192.168.0.1`，无需填写地址，可直接免密读取基础状态，仅在设备要求登录时输入后台密码；连接设置同时保留 OpenWrt 与 UFI 高级后台。另含四款桌面组件、组件预览页、产品用户群入口、无分割线纯间距界面，以及应用更名为 UULinker。

## WHY · 为什么会有这个产品？

想知道随身 Wi-Fi 还剩多少电，往往要先打开设备管理页面或专用 App。设备放在包里时，查看和确认电量更不方便。UULinker 希望把日常最关心的设备状态放到手机桌面，减少反复进入管理页面的操作。

## WHAT · 它解决了什么问题？

| 想了解的状态 | UULinker 提供的信息 |
|---|---|
| 设备还剩多少电 | 电量百分比与电池图标；无电池设备显示「插电就好啦」 |
| 是否正在充电 | 充电状态；80% 以上标记为「充电后段」 |
| 还能用多久、多久充满 | 基于电量变化估算的剩余时间与倒计时 |
| 当前网络传输情况 | 下载、上行速率；OpenWrt / 高级后台可看流量 |
| 信号与网络 | 运营商、制式、5G、RSRP / SINR / SNR / RSRQ 等实际返回字段 |
| 想少打开一个 App | 四款桌面组件、周期更新和手动刷新 |

## HOW · 它是如何解决的？

手机连接随身 Wi-Fi 的局域网后，UULinker 通过设备的本地只读接口读取数据，在 App 与桌面组件中展示。读数保存在手机本机，不经云端中转。可选的使用情况统计另见隐私说明。

- **三种接入方式**：OpenWrt 通过设备端 UULink 插件读取；UFI 高级后台通过 UFI-TOOLS 只读代理读取；原厂系统通过设备自带 goform 只读接口读取。
- **桌面组件**：默认·基础数据、All in One、曜石黑、清浅白共 4 款；可在「发现 → 高级功能 → 桌面组件」查看预览并长按桌面手动添加。
- **状态页**：通信、电池、网速与 60 秒曲线、流量、设备状态、连接设备、温度等按数据源实际返回显示；原厂系统不显示没有数据源的卡片与签约信息。
- **刷新**：App 前台持续轮询；桌面组件通过后台任务周期刷新，也可点卡片右下角手动刷新。

## 安装与使用

1. 下载上方 APK，在安卓手机打开并按系统提示允许该下载来源安装。
2. 连接设备的 Wi-Fi，打开 UULinker。
3. 在「设置 → 连接设置」选择 OpenWrt、UFI 高级后台或原厂系统。原厂系统无需填地址，直接点「连接原厂系统」；仅在设备要求登录时输入后台密码。
4. 长按桌面空白处，进入「小组件」或「窗口小工具」，添加 UULinker 卡片。默认目标尺寸为 4×2，可按桌面支持调整大小。

首次打开需阅读并同意用户协议与隐私政策；统计选择在「设置 → 隐私政策」内单独管理。与旧版签名一致，可覆盖安装；若读取失败，请附上「连接设置」返回的具体错误。

v1.6.28 Release 仅提供 APK 安装附件，SHA256 摘要写在版本说明中，可用于核对安装包完整性。旧版附件保留。

## 隐私与反馈

设备电量、充电状态和网络速率通过局域网读取，记录保存在本机；设备读取逻辑不获取随身 Wi-Fi 的 IMEI 或 Wi-Fi 名称，IMEI 仅在状态页内存显示。应用不包含广告，不要求注册账号，已关闭 Android 自动备份。

自 v1.0.1 起集成可选的百度移动统计 SDK：仅在用户允许后启用，用于 App 新增、活跃和启动等基础报表；不启用全埋点、圈选、广告或 Widget 自定义事件，不将设备电量、网速、接口响应或错误内容作为自定义统计属性上传。未允许或拒绝期间不启用统计、不保存待补报的使用历史。SDK 可能处理手机设备／网络标识，实际数据处理范围见[百度 SDK 说明](https://mtj.baidu.com/web/help/article?id=381&type=0) 。统计设备数不等于自然人人数，也不代表 APK 下载量。

可在「设置 → 隐私政策」内关闭；关闭后停止新增使用记录，先前已报送的数据不会自动删除，SDK 原有待发送队列是否清除未证实。完整说明可在 App 内离线查看。

可在本仓库 [Issues](https://github.com/MichaelJiangg/Android-UULink/issues) 反馈。建议附上手机型号、Android 版本、设备固件版本及问题现象，不要公开设备密码等敏感信息。

这是独立制作的设备状态工具，非中兴官方应用。
