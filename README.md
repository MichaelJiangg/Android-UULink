# WiFiBattery · Android

**把 U30Air 的电量、充电状态和网络速率，放到安卓桌面。**

[下载 v1.6.11 测试 APK](https://github.com/MichaelJiangg/wifibattery-android/releases/download/v1.6.11/WiFiBattery-Android-1.6.11-202610271351-test.apk) · [v1.6.11 · 演示模式与新功能许愿](https://github.com/MichaelJiangg/wifibattery-android/releases/tag/v1.6.11)

适用于 Android 8.0 及以上，支持 U30Air 原厂系统与 MU300 OpenWrt。**v1.6.11 为公开测试版，真机界面效果仍待确认。** 本仓库提供产品说明与安装包，不提供应用源码。

本版新增演示模式（连点版本 10 次进入／退出，状态页模拟通信、电量、速率、流量、设备状态与连接设备并动态变化）与「新功能许愿」入口；设置页拆分为「用户反馈」（产品反馈、新功能许愿）与「产品支持」（用户协议、隐私政策）。1.6.10 的连接设置与状态页交互优化保持不变。

## WHY · 为什么会有这个产品？

想知道随身 Wi-Fi 还剩多少电，往往要先打开设备管理页面或专用 App。设备放在包里时，查看和确认电量更不方便。WiFiBattery 希望把日常最关心的设备状态放到手机桌面，减少反复进入管理页面的操作。

## WHAT · 它解决了什么问题？

| 想了解的状态 | WiFiBattery 提供的信息 |
|---|---|
| 设备还剩多少电 | 电量百分比与电池图标 |
| 是否正在充电 | 充电状态；80% 以上标记为「充电后段」 |
| 还能用多久、多久充满 | 基于电量变化估算的剩余时间与倒计时 |
| 当前网络传输情况 | 下载、上行速率 |
| 数据是否读取成功 | connected／disconnected 角标 |
| 想少打开一个 App | 桌面小组件、周期更新和右下角手动刷新 |

## HOW · 它是如何解决的？

手机连接 U30Air 的 Wi-Fi 后，WiFiBattery 通过设备的本地只读接口获取数据，在 App 和桌面小组件中展示。设备读数保存在手机本机，不经云端中转；查看状态不需要进入高级后台，但仍要求设备原厂接口与本版兼容。可选的使用情况统计另见下方隐私说明。

- **App 内自动读取**：前台每次请求结束后等待约 5 秒，再读取下一次。
- **桌面卡片更新**：通过 Android 后台任务周期读取；也可以点击卡片右下角刷新图标，提交一次新的读取任务。
- **剩余时间估算**：根据多次有效电量变化计算趋势。样本不足时显示「—」，不编造剩余时间。

## 安装与使用

1. 下载上方 APK，在安卓手机打开并按系统提示允许该下载来源安装。
2. 连接 U30Air 的 Wi-Fi，打开 WiFiBattery，等待读取。
3. 长按桌面空白处，进入「小组件」或「窗口小工具」，添加 WiFiBattery。默认目标尺寸为 4×2，可按桌面支持调整大小。
4. 点击卡片主体打开 App；点击右下角刷新图标重新读取。

首次打开可选择是否允许使用情况统计，拒绝不影响电量读取和桌面组件。「更多 → 使用情况统计」可随时修改。与旧版签名一致，可覆盖安装；若仍读取失败，请附上「设备连接」下的具体错误。

v1.6.11 Release 仅提供 APK 安装附件，SHA256 摘要写在版本说明中，可用于核对安装包完整性。旧版附件保留。

## 隐私与反馈

设备电量、充电状态和网络速率通过局域网读取，记录保存在本机；设备读取逻辑不获取随身 Wi-Fi 的 IMEI 或 Wi-Fi 名称。应用不包含广告，不要求注册账号，已关闭 Android 自动备份。

自 v1.0.1 起集成可选的百度移动统计 SDK：仅在用户允许后启用，用于 App 新增、活跃和启动等基础报表；不启用全埋点、圈选、广告或 Widget 自定义事件，不将设备电量、网速、接口响应或错误内容作为自定义统计属性上传。未允许或拒绝期间不启用统计、不保存待补报的使用历史。SDK 可能处理手机设备／网络标识，实际数据处理范围见[百度 SDK 说明](https://mtj.baidu.com/web/help/article?id=381&type=0) 。统计设备数不等于自然人人数，也不代表 APK 下载量。

可在「更多 → 使用情况统计」关闭；关闭后停止新增使用记录，先前已报送的数据不会自动删除，SDK 原有待发送队列是否清除未证实。完整说明可在 App 内离线查看。

可在本仓库 [Issues](https://github.com/MichaelJiangg/wifibattery-android/issues) 反馈。建议附上手机型号、Android 版本、U30Air 固件版本及问题现象，不要公开设备密码等敏感信息。
