# WiFiBattery · Android

**把 U30Air 的电量、充电状态和网络速率，放到安卓桌面。**

[下载 v1.0.0 测试 APK](https://github.com/MichaelJiangg/wifibattery-android/releases/download/v1.0.0/WiFiBattery-Android-1.0.0-test.apk) · [版本说明](https://github.com/MichaelJiangg/wifibattery-android/releases/tag/v1.0.0)

适用于 Android 8.0 及以上，当前面向中兴 U30Air。**v1.0.0 为首版公开测试，尚未完成安卓真机验收。** 本仓库提供产品说明与安装包，不提供应用源码。

## WHY · 为什么会有这个产品？

想知道随身 Wi-Fi 还剩多少电，往往要先打开设备管理页面或专用 App。设备放在包里时，查看和确认电量更不方便。WiFiBattery 希望把日常最关心的设备状态放到手机桌面，减少反复进入管理页面的操作。

## WHAT · 它解决了什么问题？

| 想了解的状态 | WiFiBattery 提供的信息 |
|---|---|
| 设备还剩多少电 | 电量百分比与电池图标 |
| 是否正在充电 | 充电状态；80% 以上标记为「充电后段」 |
| 还能用多久、多久充满 | 基于电量变化估算的剩余时间与倒计时 |
| 当前网络传输情况 | 下载、上行速率 |
| 数据是否读取成功 | connected／disconnected 角标 |
| 想少打开一个 App | 桌面小组件、周期更新和右下角手动刷新 |

## HOW · 它是如何解决的？

手机连接 U30Air 的 Wi-Fi 后，WiFiBattery 通过设备的本地只读接口获取数据，在 App 和桌面小组件中展示。数据保存在手机本机，不经云端中转；查看状态不需要进入高级后台。

- **App 内自动读取**：前台每次请求结束后等待约 5 秒，再读取下一次。
- **桌面卡片更新**：通过 Android 后台任务周期读取；也可以点击卡片右下角刷新图标，提交一次新的读取任务。
- **剩余时间估算**：根据多次有效电量变化计算趋势。样本不足时显示「—」，不编造剩余时间。

## 安装与使用

1. 下载上方 APK，在安卓手机打开并按系统提示允许该下载来源安装。
2. 连接 U30Air 的 Wi-Fi，打开 WiFiBattery，等待读取。
3. 长按桌面空白处，进入「小组件」或「窗口小工具」，添加 WiFiBattery。默认目标尺寸为 4×2，可按桌面支持调整大小。
4. 点击卡片主体打开 App；点击右下角刷新图标重新读取。

GitHub Release 附件中的 `SHA256SUMS.txt` 可用于核对安装包完整性。

## v1.0.0 测试范围与已知限制

| 项目 | 当前情况 |
|---|---|
| 系统与机型 | Android 8.0 及以上；仅针对 U30Air 的兼容本地接口固件，不承诺其他机型或固件可用 |
| 已完成验证 | 编译、47 项自动化测试、静态检查零错误，以及 APK 签名和对齐校验 |
| 待完成验证 | 真实 U30Air 连接、不同安卓桌面布局／按钮、前后台与省电行为 |
| 桌面更新频率 | 周期任务约 15 分钟，受系统调度与厂商省电影响，不保证固定间隔或实时；手动任务也可能排队 |
| 连接角标 | 小组件反映最近一次读取及绘制时的状态，不能持续监测 Wi-Fi 连接 |
| 时间估算 | 属于趋势预测；「充电后段」不代表检测到真实涓流；只有实际读到充电且 100% 才显示已充满 |
| 倒计时到期 | 省电模式可能延迟到期清理，期间可能短暂显示负倒计时 |
| 强行停止 | 系统设置中的「强行停止」及部分厂商策略可能阻止后台任务，需重新打开 App |
| 签名 | 当前 APK 使用测试签名；将来更换签名可能需要卸载旧包重新安装 |

## 隐私与反馈

应用通过局域网读取设备电量、充电状态和网络速率，记录保存在本机；不读取 IMEI 或 Wi-Fi 名称，不包含广告、分析 SDK 或云端账号，已关闭 Android 自动备份。

可在本仓库 [Issues](https://github.com/MichaelJiangg/wifibattery-android/issues) 反馈。建议附上手机型号、Android 版本、U30Air 固件版本及问题现象，不要公开设备密码等敏感信息。

这是独立制作的设备状态工具，非中兴官方应用。
